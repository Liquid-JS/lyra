# Where to start?

Lyra is a set of modules for [Angular](https://angular.dev/). If Angular is new to you, go through its tutorial first.

---

## Quickstart tutorials

- [Install Lyra](docs/guides/install-lyra) sets Lyra up in a new or an existing Angular application.
- [Create Lyra Page](docs/guides/create-lyra-page) builds a first page with a header and a sidebar.

If your use case isn't covered, look through the documentation and the existing issues, then open one on GitHub.
