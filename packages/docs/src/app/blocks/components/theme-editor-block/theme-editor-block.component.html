Give the design kit this theme: install the kit's plugin, open your copy of the kit in Sketch, then run this script from Plugins › Run Script. The kit takes the theme as the app does, its colours, fonts, corners and spacing, and shows it on its Theme page, where you can change it further. Run it in your design files too, to record the theme for whoever builds them. It applies your theme over the theme you started from, e.g. Dark, as the app does.
